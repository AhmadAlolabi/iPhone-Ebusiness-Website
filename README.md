# iPhone E-Business Website

## Overview

This project was developed as part of a Web Development group assignment at Middle East College, Oman, during Spring 2025.

The original project was an iPhone-themed e-business website developed by a team of five students using HTML and CSS.

This repository contains only the home page that I developed individually as part of the team project.
